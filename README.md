# anmol-goyal.com

Personal portfolio of Anmol Goyal, served with GitHub Pages.

```
index.html            page markup and content
assets/css/style.css  styles (light + dark themes)
assets/js/main.js     theme toggle, scroll reveal, hero dot field
assets/img/           Oxford Dynamics and event photos
CNAME                 custom domain
```

To preview locally: `python3 -m http.server` and open http://localhost:8000.
